# Personal Portfolio Website

A simple multi-page personal portfolio website created using HTML only.

## About The Project

This project was created to practice the fundamentals of HTML, including:
- HTML document structure
- Semantic elements
- Links and navigation
- Images
- Tables
- Forms
- Lists
- Git and GitHub version control

## Pages

- **Home** - Introduction and learning goals
- **About Me** - Interests, hobbies, skills, and design practice
- **Contact** - Social links and feedback form

## Technologies Used

- HTML5
- Git
- GitHub

## Features

- Multi-page website
- Internal page navigation
- Clickable images
- Social media links
- Feedback form
- Organized file structure
